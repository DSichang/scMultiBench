    End-to-end walkthrough¶

    This notebook takes one method through each step: find it, check its parameters, install its environment, run it on a dataset, score its embedding and plot the scores. The method is Matilda and the dataset is D11: 2,864 blood cells measured with CITE-seq, which gives RNA and surface protein (ADT) for each cell.

    find_methods → params_for → env.install → run → evaluate → plot.bubble

    The category tutorials run several methods at once with the same run. Methods run on Linux. On macOS or Windows, open this notebook in Colab.

    1. Install¶

    This cell installs multibench-sc. It keeps the numpy and pandas that are already installed, so Colab needs no restart.

    Details

    On Colab, choose a GPU runtime before you run the notebook: Runtime -> Change runtime type -> T4 GPU. On a CPU runtime, an environment that has a smaller CPU build gets that build, and training methods run slower.

    4. Check the parameters¶

    5. Install the environment¶

    Matilda runs in its own environment. mtb.env.install downloads it, with no conda needed. The download is 0.6 GB on a computer without a GPU and 3.0 GB on one with a GPU.

    6. Run¶

    run runs Matilda on D11, scores its embedding and saves the result under out/. params={"Matilda": {"epochs": 10}} shortens training for this demo. res.embedding("Matilda") returns the embedding as an AnnData: one row per cell, named by its barcode, with its cell type in obs["label"].

    Details

    res.summary has the status and the scores of the run, and its reason column says why a method failed.

    mtb.scan("D11", "vertical", methods=["Matilda"]) returns the plan and the command without running anything. It works on any computer.

    7. Score¶

    evaluate scores the embedding against the cell types in emb.obs["label"] and returns a long table, one row per metric. method= and dataset= name the rows.

    Details

    metrics="clustering" computes ARI, NMI, ASW, iASW, iF1 and cLISI. D11 has a single batch, so the batch metrics do not apply.

    For an embedding file, mtb.evaluate(path, dataset="D11", category="vertical", method="Matilda") matches the dataset's label files to the cells by the barcodes run writes into the file.

    Scores of this run differ a little from the stored ones: most methods give a slightly different embedding on each run.

    8. Plot¶

    The cell adds this run to the package's stored results of D11 and plots them together.

    Details

    Circle size shows the rank within a column, and bigger is better. The fill compares a value with the other rows in the same column.

    The stored results cover one dataset per category. Rows from your own dataset go in a figure of their own.

    In [9]:
    Copied! 
    stored = mtb.load_results("vertical", dataset="D11")
mtb.plot.bubble(pd.concat([stored, scores], ignore_index=True))

    Summary¶

    step API
    find a method find_methods, method_info
    get the data data.fetch, scan
    check the parameters params_for
    install the environment mtb.env.install
    run run(..., methods=[...], params={...}), embedding
    score evaluate
    plot load_results, plot.bubble

    The category tutorials (vertical, diagonal, mosaic, cross) run and score several methods in one call, on the demo data and on your own.
