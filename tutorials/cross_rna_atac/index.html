    Cross integration: Multiple RNA + ATAC¶

    Cross integration combines batches that all measure the same modalities. The task is to remove batch effects and keep the biological structure. This tutorial is for batches that each hold RNA and ATAC peaks. It runs StabMap and scMM on D56mini, 4,500 cells in three batches, cut from the first three batches of the benchmark dataset D56, and then on data in your own format.

    Methods run on Linux. On macOS or Windows, open this notebook in Colab: sections 1 to 4 take about 8 minutes there.

    3. Run the methods¶

    run runs each method on D56mini and scores its output. The clustering metrics score how well the embedding's clusters and neighbourhoods match the cell types, and how separate the clusters are. The batch metrics measure how well the batches mix. The classification scores measure how well the cell types learned on one batch are predicted in the other batches. Higher is better for every metric.

    Details

    params={"Method": {"key": value}} sets a method's parameters, and mtb.params_for lists them.

    mtb.load_run("out/D56mini") reloads these results later.

    4. Plot¶

    res.plot() draws the scores as a bubble table. Circle size ranks the rows within each column and colour shows the value scaled per column, so a small gap can look large. res.summary has the values.

    Details

    Metrics are grouped by family: blue for clustering, green for batch correction, pink for classification. Each family starts with an Overall bar: each row's mean rank over the family's metrics, scaled so that the lowest gets the shortest bar.

    A column with fewer than two different values is drawn grey. A figure of one method is grey everywhere.

    5. Your own data¶

    Your data needs raw RNA counts in one .h5ad file and an ATAC peak matrix of the same cells in another, with a cell type and a batch for each cell. Give the same peaks in every batch.

    The methods of this task read three batches, and UINMF also reads two.

    Recipes cover a 10x .h5 file, labels in a CSV file, no labels and another number of donors.

    Details: export

    The names in quotes say where your file holds each part. "X" is the main matrix, "obsm:atac" the matrix obsm["atac"], "layer:counts" the layer layers["counts"], and "obs:celltype" the column obs["celltype"]. A wrong name after obsm:, layer: or obs: raises an error that lists the names the file has.

    The batches are numbered in the sorted order of their names, read as text: donors A, B and C become batches 1, 2 and 3, and 10 comes before 2.

    For one AnnData per batch, call export_dataset once per batch with batch_index=N instead of batch=.

    The next cell writes two small example files, my_rna.h5ad and my_atac.h5ad, from 60% of the cells of D56mini, with a batch column. Skip it for your own data.

    6. Every method of this task¶

    8 methods run this task. This notebook runs them all. Its 6 environments download 19.6 GB on a computer without a GPU and 23.0 GB on one with a GPU.

    Troubleshooting¶

    res.summary[res.summary.status != "scored"] lists each method that failed or was skipped. Its reason column ends with the method's error output.

    Details
    symptom fix
    a method fails on a small dataset mtb.scan names what the method needs from the data's size in its caveat column
    a method times out raise timeout= in run
    batch metrics use the wrong batches res.rescore(batch=my_vector) scores again without running the methods
